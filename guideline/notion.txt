## 1. 과제 안내

### 과제 배경

슬리피 고객은 제품 기능, 사용 방법, 구매 절차 등에 대해 반복적으로 문의할 수 있으나 초기 스타트업 특성상 신속하고 일관된 대응에 한계가 있습니다.

이에 제품 자료와 FAQ를 기반으로 질문에 자동 답변하고, 필요한 경우 상담이나 문의 접수로 연결할 수 있는 **홈페이지용 AI 고객상담 챗봇**을 개발합니다.

### 필수 수행 범위

- 제품 특징·사용 방법·유의사항·구매 방법 질의응답
- 자연어 질문 입력 및 AI 답변 제공
- 제품 자료·FAQ 기반 문서 검색 및 답변 생성
- 답변 근거가 된 문서 또는 FAQ 항목 표시
- 대화 내용 초기화·재질문 기능
- 답변이 불확실한 경우 추측을 최소화하고 담당자 문의 유도
- 문의 폼 또는 상담 채널 연결
- 홈페이지 삽입 또는 독립 실행 가능한 챗봇 UI
- PC·모바일 환경 대응
- 실제 접속 가능한 주소에 배포

### 답변 품질 평가

- 대표 질문 및 실제 고객 문의 사례 기반 **20~30건 평가 세트** 구성
- 답변을 정답·부분 정답·오답·근거 없는 답변으로 분류
- 자료에 없는 질문 및 관련 없는 질문 대응 점검
- 오류 사례와 개선 전후 결과 정리

### 도전 과제

- 자주 묻는 질문 버튼 등 대화 시작 UI
- 질문 기록 확인용 간단한 로그 화면
- 사용량·응답 시간 측정 및 운영 비용 추정
- 서로 다른 답변 설정을 동일 평가 세트로 비교

### 범위 제외

- 모델 학습 및 파인튜닝
- 실제 고객 데이터를 활용한 운영
- 상담원 배정 및 티켓 관리 시스템
- 상용 수준의 인증·보안 체계 구축

### 구성 단계

**1주차 | 제품 자료·FAQ 이해 및 설계**

- 제품 설명·사용 방법·구매 안내 자료 확인
- 고객 문의 유형 정리
- 챗봇 답변 범위 설정
- 질문 → 답변 → 상담 연결 흐름 설계
- 평가용 대표 질문 20~30건 초안 작성
- 웹서비스 개발팀과 홈페이지 삽입 방식 협의

**2주차 | AI 답변 기능 구현**

- 제품 자료·FAQ 문서 정리 및 검색 기능 개발
- 검색 결과 기반 답변 생성 연결
- 답변 근거 표시 방식 구현

**3주차 | 챗봇 화면 및 상담 연결**

- 홈페이지용 챗봇 화면 제작
- 답변 어려움 시 문의 폼·상담 채널 연결
- 실제 접속 가능한 주소에 배포

**4주차 | 품질 평가 및 결과 정리**

- 평가 세트 기반 답변 측정·유형 분류
- 오류 사례 반영 후 동일 세트 재측정
- 웹서비스 개발팀 홈페이지와 삽입 연동 확인
- README·평가 리포트·발표자료 정리 및 시연

### 최종 제출물

- 배포된 챗봇
- GitHub 저장소 및 실행 방법을 포함한 README
- 답변 품질 평가 리포트
- 발표자료
