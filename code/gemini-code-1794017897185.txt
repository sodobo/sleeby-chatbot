[2. app/api/chat/route.ts - POST /api/chat R02 단일 엔드포인트 구현][cite: 16]
- 요청: { "message": string, "history"?: array }[cite: 16]
- 응답 JSON 구조 (HTTP 200)[cite: 16]:
  {
    "status": "answered" | "clarification_needed" | "insufficient_context" | "support_required",
    "answer": string,
    "sources": [ { "document_id": string, "title": string, "faq_id": string|null, "location": string|null } ],
    "needs_support": boolean,
    "support_url": string | null,
    "follow_up_question": string | null
  }
- 빈 질문 시 HTTP 400 { "error": { "code": "EMPTY_MESSAGE", "message": "질문을 입력해 주세요." } } 반환[cite: 16]

- 하단: 질문 입력창 및 전송 버튼[cite: 16]
